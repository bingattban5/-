# 🎬 VSub — تحميل الفيديو و الترجمة

> **Download videos and extract subtitles with AI — fully offline**
> **تحميل الفيديوهات واستخراج الترجمات بالذكاء الاصطناعي — يعمل بدون إنترنت**

**VSub** (تحميل الفيديو و الترجمة) هو تطبيق أندرويد مفتوح المصدر يتيح لك تحميل الفيديوهات من أكثر من 1000 موقع، واستخراج الترجمات تلقائياً باستخدام الذكاء الاصطناعي على جهازك، وترجمتها إلى العربية — كل ذلك دون الحاجة لاتصال بالإنترنت أثناء المعالجة.

---

## ✨ المميزات

### 🎥 تحميل الفيديوهات
- دعم **+1000 موقع** (YouTube، TikTok، Instagram، Twitter/X، Facebook، Vimeo، وغيرها)
- اختيار جودة التحميل من 144p حتى أعلى جودة متاحة
- **إيقاف مؤقت، استئناف، وإلغاء** التحميلات في أي لحظة
- تحميل في الخلفية مع إشعارات فورية وشريط تقدم مباشر

### 🤖 ذكاء اصطناعي على الجهاز (Offline AI)
- **Faster-Whisper**: تحويل الصوت إلى نص وتوليد ترجمات للفيديوهات التي لا تحتوي على ترجمة
- **Argos Translate**: ترجمة الترجمات الأجنبية إلى العربية بدون إنترنت
- **الترجمة المتتابعة (Pivot)**: دعم لغات غير مدعومة مباشرة عبر الترجمة عبر الإنجليزية

### 📁 مدير ملفات متقدم
- عرض شبكي (Grid) وقائمة (List) بتبديل سلس
- بحث وتصفية حسب نوع الملف
- كشف الملفات المكررة وحذفها
- تنظيف الملفات المؤقتة لتوفير المساحة
- معاينة ومشاركة ملفات الترجمة SRT

### 🎨 تجربة استخدام عصرية
- تصميم **Material Design 3** بتأثيرات زجاجية (Glassmorphism) وتدرجات لونية
- **وضع ليلي ونهاري** قابل للتخصيص
- حركات وانتقالات سلسة
- دعم كامل للغة العربية (RTL)

### 🔐 ميزات متقدمة
- دعم ملفات **Cookies** للوصول إلى المواقع المحمية بالتحقق من العمر
- دعم معمارية **ARM 64-bit**
- إدارة ذكية لمساحة التخزين

## 🛠️ التقنيات المستخدمة

| التقنية | الاستخدام |
|---------|-----------|
| **Kotlin + Jetpack Compose** | بناء واجهة المستخدم |
| **Hilt** | حقن الاعتماديات (Dependency Injection) |
| **WorkManager** | التحميل في الخلفية |
| **yt-dlp** | استخراج الفيديوهات من المواقع |
| **Faster-Whisper** | تحويل الصوت إلى نص |
| **Argos Translate** | الترجمة بدون إنترنت |
| **FFmpeg** | معالجة الوسائط |
| **Room / DataStore** | التخزين المحلي |

## 📐 المعمارية

يتبع التطبيق مبادئ **Clean Architecture** مع نمط **MVVM**:

```
app/src/main/java/com/agon/app/
├── data/          # طبقة البيانات (Room, DataStore, Repositories)
├── domain/        # طبقة المنطق (Use Cases)
├── engine/        # محركات الذكاء الاصطناعي (yt-dlp, Whisper, Argos)
├── worker/        # المهام الخلفية (WorkManager)
├── viewmodel/     # إدارة الحالة (MVVM + StateFlow)
└── ui/            # واجهة المستخدم (Jetpack Compose)
```

## 🚀 البناء والتشغيل

```bash
git clone https://github.com/bingattban5/VSub.git
cd subdownVr3
./gradlew assembleDebug
```

ثم ثبّت ملف APK الناتج من `app/build/outputs/apk/debug/`.
